# 2-minute demo video script

| Time | Show | Say |
|---|---|---|
| 0:00-0:10 | Title, Kalimati price chart | Farmers selling into Kalimati decide every week when to harvest and sell, with no price outlook and only a basic phone. |
| 0:10-0:25 | Chat simulator: New farmer, `hello`, `1`, `4` | Any SMS gets a welcome; 1 starts; the farmer picks their district from the weather file. |
| 0:25-0:40 | Tap `1`, `1` (tomato price), then type `golbheda` | Menu or short free text in Roman Nepali, Nepali or English. Every reply fits in at most two SMS; the meter shows it. |
| 0:40-1:00 | `tomato 14 din`, then `cauli forecast` | Forecasts are ranges with an honest label: this one is a seasonal pattern, not a forecast; cauliflower 14 days passed our reliability gate. |
| 1:00-1:10 | `3`, `1` weather; `next month rain` | Weather for the farmer's own district; beyond two weeks it says climatology. |
| 1:10-1:40 | Test Console trace, Scenario runner, Models matrix and footprint | No LLM at runtime: rules, aliases and a tiny classifier. All 37 scenarios pass. Every cell's backtest and the model footprint are on the Models page. |
| 1:40-1:55 | Overview, Conversations live, Market fan chart | Operators see usage, latency, cost and every conversation live. |
| 1:55-2:00 | README limitations | Wholesale not farm-gate, 3 years of prices, translations need review. Next: real SMS and a pilot. |
